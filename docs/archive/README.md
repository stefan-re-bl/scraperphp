# Archivo histórico

Instantánea documental archivada el **2026-10-15**, antes de consolidar los manuales. Conserva auditorías, decisiones, verificaciones e instrucciones de etapas anteriores. Sus estados, rutas citadas y recomendaciones pueden estar superados; no deben utilizarse como configuración operativa actual.

La [documentación vigente](../README.md) distingue procedimientos, estado y pendientes. Se conserva el contenido de los originales, con una advertencia de archivo y enlaces relativos ajustados a su nueva ubicación. Los datos privados de importación/activación no se incluyen en este archivo público.

## Agregar otra entrega cerrada

Usa una carpeta con fecha, identifica alcance y evidencia, conserva el informe sin reescribir sus resultados para reflejar cambios futuros y enlázalo desde Changelog. Las instrucciones actuales permanecen en su documento responsable. Una verificación local, una activación y un resultado comercial son evidencias diferentes.
